# Examples

Complete example Intent Files:

- [`orders.intent`](orders.intent) — a single-file application exercising every top-level
  block: entities with a setting and a composition, a workflow with a decision, a form, a
  report, roles and seed data.

For a walked-through multi-model example (several intent projects referencing each other's
master data through `uses:`), see [intentfile.org/examples](https://intentfile.org/examples).
