# Proposals

Larger specification changes start here: copy [`0000-template.md`](0000-template.md) to
`NNNN-short-name.md` (next free number), fill it in, and open a pull request. Discussion
happens on that PR; once the direction converges, a follow-up PR specifies the construct
in the current version document (see [CONTRIBUTING.md](../CONTRIBUTING.md)).

Smaller changes don't need a proposal document — an
[issue](https://github.com/IntentFile/intent-specification/issues/new/choose) is enough.
